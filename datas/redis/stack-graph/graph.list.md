# GRAPH.LIST

Source: https://devdocs.io/redis/graph.list/index

```
GRAPH.LIST
```

```
GRAPH.LIST
```

Lists all graph keys in the keyspace.

```
127.0.0.1:6379> GRAPH.LIST
2) G
3) resources
4) players
```
