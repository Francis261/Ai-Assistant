# ACL

Source: https://devdocs.io/redis/acl-users/index

```
ACL USERS
```

```
ACL USERS
```

The command shows a list of all the usernames of the currently configured users in the Redis ACL system.

## Return

An array of strings.

## Examples

```
> ACL USERS
1) "anna"
2) "antirez"
3) "default"
```
