# Command Line Interface

Source: https://devdocs.io/vite~6/guide/cli#vite-optimize

## Dev server

### vite

Start Vite dev server in the current directory. vite dev and vite serve are aliases for vite.

#### Usage

```
vite [root]
```

#### Options

## Build

### vite build

Build for production.

#### Usage

```
vite build [root]
```

## Others

### vite optimize

Pre-bundle dependencies.

Deprecated: the pre-bundle process runs automatically and does not need to be called.

#### Usage

```
vite optimize [root]
```

#### Options

### vite preview

Locally preview the production build. Do not use this as a production server as it's not designed for it.

#### Usage

```
vite preview [root]
```
