# GearmanClient::clone

Source: https://devdocs.io/php/gearmanclient.clone

(PECL gearman >= 0.5.0)

GearmanClient::clone — Create a copy of a GearmanClient object

### Description

```
public GearmanClient::clone(): GearmanClient
```

Creates a copy of a GearmanClient object.

### Parameters

This function has no parameters.

### Return Values

A GearmanClient on success, false on failure.
