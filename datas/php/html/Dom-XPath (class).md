# The Dom\XPath class

Source: https://devdocs.io/php/class.dom-xpath

## Introduction

(PHP 8 >= 8.4.0)

Allows to use XPath 1.0 queries on HTML or XML documents.

This is the modern, spec-compliant equivalent of DOMXPath.
