# DOMNode::__wakeup

Source: https://devdocs.io/php/domnode.wakeup

(PHP 8 PHP 8 >= 8.1.25)

DOMNode::__wakeup — Forbids unserialization unless unserialization methods are implemented in a subclass

### Description

```
public DOMNode::__wakeup(): void
```

Forbids unserialization unless unserialization methods are implemented in a subclass.

### Parameters

This function has no parameters.

### Return Values

The method always throws an exception.

### Errors/Exceptions

Throws an Error exception when called.
