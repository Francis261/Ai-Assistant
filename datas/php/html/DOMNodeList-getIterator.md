# DOMNodeList::getIterator

Source: https://devdocs.io/php/domnodelist.getiterator

(PHP 8)

DOMNodeList::getIterator — Retrieve an external iterator

### Description

```
public DOMNodeList::getIterator(): Iterator
```

Returns an external iterator for the node list.

### Parameters

This function has no parameters.

### Return Values

An instance of an object implementing Iterator or Traversable

### Errors/Exceptions

Throws an Exception on failure.
