# eio_set_max_poll_time

Source: https://devdocs.io/php/function.eio-set-max-poll-time

(PECL eio >= 0.0.1dev)

eio_set_max_poll_time — Set maximum poll time

### Description

```
eio_set_max_poll_time(float $nseconds): void
```

Polling stops, if poll took longer than nseconds seconds.

### Parameters

Number of seconds

### Return Values

No value is returned.
