# eio_sync

Source: https://devdocs.io/php/function.eio-sync

(PECL eio >= 0.0.1dev)

eio_sync — Commit buffer cache to disk

### Description

```
eio_sync(int $pri = EIO_PRI_DEFAULT, callable $callback = NULL, mixed $data = NULL): resource
```

### Parameters

This function has no parameters.

### Return Values

eio_sync() returns request resource on success, or false on failure.
