# EvPrepare::__construct

Source: https://devdocs.io/php/evprepare.construct

(PECL ev >= 0.2.0)

EvPrepare::__construct — Constructs EvPrepare watcher object

### Description

Constructs EvPrepare watcher object. And starts the watcher automatically. If need a stopped watcher consider using EvPrepare::createStopped()

### Parameters

See Watcher callbacks.

Custom data associated with the watcher.

Watcher priority
