# Throwable::getTrace

Source: https://devdocs.io/php/throwable.gettrace

(PHP 7, PHP 8)

Throwable::getTrace — Gets the stack trace

### Description

```
public Throwable::getTrace(): array
```

Returns the stack trace as an array.

### Parameters

This function has no parameters.

### Return Values

Returns the stack trace as an array in the same format as debug_backtrace().
