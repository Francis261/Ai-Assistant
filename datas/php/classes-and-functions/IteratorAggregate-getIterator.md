# IteratorAggregate::getIterator

Source: https://devdocs.io/php/iteratoraggregate.getiterator

(PHP 5, PHP 7, PHP 8)

IteratorAggregate::getIterator — Retrieve an external iterator or traversable

### Description

```
public IteratorAggregate::getIterator(): Traversable
```

Returns an external iterator or traversable.

### Parameters

This function has no parameters.

### Return Values

An instance of an object implementing Iterator or Traversable

### Errors/Exceptions

Throws an Exception on failure.
