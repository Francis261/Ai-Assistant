# intltz_get_region

(PHP 5 >= 5.5.0, PHP 7, PHP 8)

IntlTimeZone::getRegion -- intltz_get_region — Get the region code associated with the given system time zone ID

### Description

Object-oriented style (method):

```
public static IntlTimeZone::getRegion(string $timezoneId): string|false
```

Procedural style:

```
intltz_get_region(string $timezoneId): string|false
```

This function is currently not documented; only its argument list is available.

### Parameters

### Return Values

Return region or false on failure.
