# SplPriorityQueue::recoverFromCorruption

Source: https://devdocs.io/php/splpriorityqueue.recoverfromcorruption

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

SplPriorityQueue::recoverFromCorruption — Recover from the corrupted state and allow further actions on the queue

### Description

```
public SplPriorityQueue::recoverFromCorruption(): true
```

### Parameters

This function has no parameters.

### Return Values

Always returns true.
