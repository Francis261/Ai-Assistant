# SplHeap::insert

Source: https://devdocs.io/php/splheap.insert

(PHP 5 >= 5.3.0, PHP 7, PHP 8)

SplHeap::insert — Inserts an element in the heap by sifting it up

### Description

```
public SplHeap::insert(mixed $value): true
```

Insert value in the heap.

### Parameters

The value to insert.

### Return Values

Always returns true.
