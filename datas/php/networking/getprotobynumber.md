# getprotobynumber

Source: https://devdocs.io/php/function.getprotobynumber

(PHP 4, PHP 5, PHP 7, PHP 8)

getprotobynumber — Get protocol name associated with protocol number

### Description

```
getprotobynumber(int $protocol): string|false
```

getprotobynumber() returns the protocol name associated with protocol protocol as per /etc/protocols.

### Parameters

The protocol number.

### Return Values

Returns the protocol name as a string, or false on failure.
