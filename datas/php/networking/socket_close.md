# socket_close

Source: https://devdocs.io/php/function.socket-close

(PHP 4 >= 4.1.0, PHP 5, PHP 7, PHP 8)

socket_close — Closes a Socket instance

### Description

```
socket_close(Socket $socket): void
```

socket_close() closes the Socket instance given by socket.

### Parameters

A Socket instance created with socket_create() or socket_accept().

### Return Values

No value is returned.
