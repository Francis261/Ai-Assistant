# dcngettext

Source: https://devdocs.io/php/function.dcngettext

(PHP 4 >= 4.2.0, PHP 5, PHP 7, PHP 8)

dcngettext — Plural version of dcgettext

### Description

```
dcngettext(
 string $domain,
 string $singular,
 string $plural,
 int $count,
 int $category
): string
```

This function allows you to override the current domain for a single plural message lookup.

### Parameters

The domain

### Return Values

A string on success.
