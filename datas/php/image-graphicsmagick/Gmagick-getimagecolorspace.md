Gmagick::getimagecolorspace — Gets the image colorspace

### Description

```
public Gmagick::getimagecolorspace(): int
```

Gets the image colorspace.

### Parameters

This function has no parameters.

### Return Values

Colorspace

### Errors/Exceptions

Throws an GmagickException on error.
