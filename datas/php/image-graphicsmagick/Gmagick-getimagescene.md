Gmagick::getimagescene — Gets the image scene

### Description

```
public Gmagick::getimagescene(): int
```

Gets the image scene.

### Parameters

This function has no parameters.

### Return Values

Returns the image scene.

### Errors/Exceptions

Throws an GmagickException on error.
