# Gmagick::setsamplingfactors

Source: https://devdocs.io/php/gmagick.setsamplingfactors

(PECL gmagick >= Unknown)

Gmagick::setsamplingfactors — Sets the image sampling factors

### Description

```
public Gmagick::setsamplingfactors(array $factors): Gmagick
```

Sets the image sampling factors.

### Parameters

An array of floats representing the sampling factor for each color component (in RGB order).

### Return Values

The Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
