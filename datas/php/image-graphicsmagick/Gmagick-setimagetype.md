# Gmagick::setimagetype

Source: https://devdocs.io/php/gmagick.setimagetype

(PECL gmagick >= Unknown)

Gmagick::setimagetype — Sets the image type

### Description

```
public Gmagick::setimagetype(int $imgType): Gmagick
```

Sets the image type.

### Parameters

One of the Image type constant (Gmagick::IMGTYPE_*).

### Return Values

The Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
