# Gmagick::flopimage

Source: https://devdocs.io/php/gmagick.flopimage

(PECL gmagick >= Unknown)

Gmagick::flopimage — Creates a horizontal mirror image

### Description

```
public Gmagick::flopimage(): Gmagick
```

Creates a horizontal mirror image by reflecting the pixels around the central y-axis.

### Parameters

This function has no parameters.

### Return Values

The flopped Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.

### See Also

- Gmagick::flipimage() - Creates a vertical mirror image
