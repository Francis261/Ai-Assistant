# Gmagick::setfilename

Source: https://devdocs.io/php/gmagick.setfilename

(PECL gmagick >= Unknown)

Gmagick::setfilename — Sets the filename before you read or write the image

### Description

```
public Gmagick::setfilename(string $filename): Gmagick
```

Sets the filename before you read or write an image file.

### Parameters

The image filename.

### Return Values

The Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
