# Gmagick::readimage

Source: https://devdocs.io/php/gmagick.readimage

(PECL gmagick >= Unknown)

Gmagick::readimage — Reads image from filename

### Description

```
public Gmagick::readimage(string $filename): Gmagick
```

Reads image from filename.

### Parameters

The image filename.

### Return Values

The Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
