# Gmagick::setimagefilename

Source: https://devdocs.io/php/gmagick.setimagefilename

(PECL gmagick >= Unknown)

Gmagick::setimagefilename — Sets the filename of a particular image in a sequence

### Description

```
public Gmagick::setimagefilename(string $filename): Gmagick
```

Sets the filename of a particular image in a sequence.

### Parameters

The image filename.

### Return Values

The Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
