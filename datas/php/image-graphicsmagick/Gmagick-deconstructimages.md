# Gmagick::deconstructimages

Source: https://devdocs.io/php/gmagick.deconstructimages

(PECL gmagick >= Unknown)

Gmagick::deconstructimages — Returns certain pixel differences between images

### Description

```
public Gmagick::deconstructimages(): Gmagick
```

Compares each image with the next in a sequence and returns the maximum bounding region of any pixel differences it discovers.

### Parameters

This function has no parameters.

### Return Values

Returns a new Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
