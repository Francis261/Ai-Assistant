Source: https://devdocs.io/php/gmagick.setimagedispose

Gmagick::setimagedispose — Sets the image disposal method

### Description

```
public Gmagick::setimagedispose(int $disposeType): Gmagick
```

Sets the image disposal method.

### Parameters

The image disposal type.

### Return Values

The Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
