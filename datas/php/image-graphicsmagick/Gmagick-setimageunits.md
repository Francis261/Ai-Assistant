# Gmagick::setimageunits

Source: https://devdocs.io/php/gmagick.setimageunits

(PECL gmagick >= Unknown)

Gmagick::setimageunits — Sets the image units of resolution

### Description

```
public Gmagick::setimageunits(int $resolution): Gmagick
```

Sets the image units of resolution.

### Parameters

One of the Resolution constant (Gmagick::RESOLUTION_*).

### Return Values

The Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
