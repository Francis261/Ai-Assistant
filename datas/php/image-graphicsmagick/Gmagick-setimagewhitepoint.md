Gmagick::setimagewhitepoint — Sets the image chromaticity white point

### Description

```
public Gmagick::setimagewhitepoint(float $x, float $y): Gmagick
```

Sets the image chromaticity white point.

### Parameters

The white x-point.

The white y-point.

### Return Values

The Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
