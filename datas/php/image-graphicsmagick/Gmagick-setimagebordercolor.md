# Gmagick::setimagebordercolor

Source: https://devdocs.io/php/gmagick.setimagebordercolor

(PECL gmagick >= Unknown)

Gmagick::setimagebordercolor — Sets the image border color

### Description

```
public Gmagick::setimagebordercolor(GmagickPixel $color): Gmagick
```

Sets the image border color.

### Parameters

The border pixel wand.

### Return Values

The Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
