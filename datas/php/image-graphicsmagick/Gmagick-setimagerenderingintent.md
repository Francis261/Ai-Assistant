# Gmagick::setimagerenderingintent

Source: https://devdocs.io/php/gmagick.setimagerenderingintent

(PECL gmagick >= Unknown)

Gmagick::setimagerenderingintent — Sets the image rendering intent

### Description

```
public Gmagick::setimagerenderingintent(int $rendering_intent): Gmagick
```

Sets the image rendering intent.

### Parameters

One of the Rendering Intent constant (Gmagick::RENDERINGINTENT_*).

### Return Values

The Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
