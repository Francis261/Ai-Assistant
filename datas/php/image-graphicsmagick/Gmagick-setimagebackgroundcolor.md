# Gmagick::setimagebackgroundcolor

Source: https://devdocs.io/php/gmagick.setimagebackgroundcolor

(PECL gmagick >= Unknown)

Gmagick::setimagebackgroundcolor — Sets the image background color

### Description

```
public Gmagick::setimagebackgroundcolor(GmagickPixel $color): Gmagick
```

Sets the image background color.

### Parameters

The background pixel wand.

### Return Values

The Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
