# Gmagick::newimage

Source: https://devdocs.io/php/gmagick.newimage

(PECL gmagick >= Unknown)

Gmagick::newimage — Creates a new image

### Description

```
public Gmagick::newimage(
 int $width,
 int $height,
 string $background,
 string $format = ?
): Gmagick
```

Creates a new image with the specified background color.

### Parameters

Width of the new image.

Height of the new image.

The background color used for this image (as float).

Image format.

### Return Values

The Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
