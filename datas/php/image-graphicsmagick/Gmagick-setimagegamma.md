# Gmagick::setimagegamma

Source: https://devdocs.io/php/gmagick.setimagegamma

(PECL gmagick >= Unknown)

Gmagick::setimagegamma — Sets the image gamma

### Description

```
public Gmagick::setimagegamma(float $gamma): Gmagick
```

Sets the image gamma.

### Parameters

The image gamma.

### Return Values

The Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
