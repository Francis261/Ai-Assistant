# Gmagick::setimageblueprimary

Source: https://devdocs.io/php/gmagick.setimageblueprimary

(PECL gmagick >= Unknown)

Gmagick::setimageblueprimary — Sets the image chromaticity blue primary point

### Description

```
public Gmagick::setimageblueprimary(float $x, float $y): Gmagick
```

Sets the image chromaticity blue primary point.

### Parameters

The blue primary x-point.

The blue primary y-point.

### Return Values

The Gmagick object.

### Errors/Exceptions

Throws an GmagickException on error.
