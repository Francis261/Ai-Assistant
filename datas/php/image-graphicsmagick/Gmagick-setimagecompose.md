# Gmagick::setimagecompose

Source: https://devdocs.io/php/gmagick.setimagecompose

(PECL gmagick >= Unknown)

Gmagick::setimagecompose — Sets the image composite operator

### Description

```
public Gmagick::setimagecompose(int $composite): Gmagick
```

Sets the image composite operator.

### Parameters

The image composite operator.

### Return Values

The Gmagick object on success

### Errors/Exceptions

Throws an GmagickException on error.
