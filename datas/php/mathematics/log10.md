# log10

Source: https://devdocs.io/php/function.log10

(PHP 4, PHP 5, PHP 7, PHP 8)

log10 — Base-10 logarithm

### Description

```
log10(float $num): float
```

Returns the base-10 logarithm of num.

### Parameters

The argument to process

### Return Values

The base-10 logarithm of num
