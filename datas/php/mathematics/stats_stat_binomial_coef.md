# stats_stat_binomial_coef

Source: https://devdocs.io/php/function.stats-stat-binomial-coef

(PECL stats >= 1.0.0)

stats_stat_binomial_coef — Returns a binomial coefficient

### Description

```
stats_stat_binomial_coef(int $x, int $n): float
```

Returns the binomial coefficient of n choose x.

### Parameters

The number of chooses from the set

The number of elements in the set

### Return Values

Returns the binomial coefficient
