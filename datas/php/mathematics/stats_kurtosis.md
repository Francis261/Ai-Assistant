# stats_kurtosis

Source: https://devdocs.io/php/function.stats-kurtosis

(PECL stats >= 1.0.0)

stats_kurtosis — Computes the kurtosis of the data in the array

### Description

```
stats_kurtosis(array $a): float
```

Returns the kurtosis of the values in a.

### Parameters

The input array

### Return Values

Returns the kurtosis of the values in a, or false if a is empty or is not an array.
