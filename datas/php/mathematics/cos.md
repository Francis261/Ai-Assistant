# cos

Source: https://devdocs.io/php/function.cos

(PHP 4, PHP 5, PHP 7, PHP 8)

cos — Cosine

### Description

```
cos(float $num): float
```

cos() returns the cosine of the num parameter. The num parameter is in radians.

### Parameters

An angle in radians

### Return Values

The cosine of num

### Examples

Example #1 cos() example

```
<?php

echo cos(M_PI); // -1

?>
```
