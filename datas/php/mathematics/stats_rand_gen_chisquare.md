# stats_rand_gen_chisquare

Source: https://devdocs.io/php/function.stats-rand-gen-chisquare

(PECL stats >= 1.0.0)

stats_rand_gen_chisquare — Generates a random deviate from the chi-square distribution

### Description

```
stats_rand_gen_chisquare(float $df): float
```

Returns a random deviate from the chi-square distribution where the degrees of freedom is df.

### Parameters

The degrees of freedom

### Return Values

A random deviate
