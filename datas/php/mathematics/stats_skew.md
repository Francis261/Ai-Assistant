# stats_skew

Source: https://devdocs.io/php/function.stats-skew

(PECL stats >= 1.0.0)

stats_skew — Computes the skewness of the data in the array

### Description

```
stats_skew(array $a): float
```

Returns the skewness of the values in a.

### Parameters

The input array

### Return Values

Returns the skewness of the values in a, or false if a is empty or is not an array.
