# stats_rand_setall

Source: https://devdocs.io/php/function.stats-rand-setall

(PECL stats >= 1.0.0)

stats_rand_setall — Set seed values to the random generator

### Description

```
stats_rand_setall(int $iseed1, int $iseed2): void
```

Set iseed1 and iseed2 as seed values to the random generator used in statistic functions.

### Parameters

The value which is used as the random seed

The value which is used as the random seed

### Return Values

No values are returned.
