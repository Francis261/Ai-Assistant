# The RoundingMode Enum

Source: https://devdocs.io/php/enum.roundingmode

## Introduction

(PHP 8 >= 8.4.0)

The RoundingMode enum is used to specify how rounding should be performed for round(), bcround(), and BcMath\Number::round().
