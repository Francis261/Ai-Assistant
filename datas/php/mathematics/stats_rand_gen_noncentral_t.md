# stats_rand_gen_noncentral_t

Source: https://devdocs.io/php/function.stats-rand-gen-noncentral-t

(PECL stats >= 1.0.0)

stats_rand_gen_noncentral_t — Generates a single random deviate from a non-central t-distribution

### Description

```
stats_rand_gen_noncentral_t(float $df, float $xnonc): float
```

Returns a random deviate from the non-central t-distribution with the degrees of freedom, df, and the non-centrality parameter, xnonc.

### Parameters

The degrees of freedom

The non-centrality parameter

### Return Values

A random deviate
