# chop

Source: https://devdocs.io/php/function.chop

(PHP 4, PHP 5, PHP 7, PHP 8)

chop — Alias of rtrim()

### Description

This function is an alias of: rtrim().

### Notes

Note:

chop() is different than the Perl chop() function, which removes the last character in the string.
