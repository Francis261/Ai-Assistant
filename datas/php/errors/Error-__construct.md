# Error::__construct

Source: https://devdocs.io/php/error.construct

(PHP 7, PHP 8)

Error::__construct — Construct the error object

### Description

Constructs the Error.

### Parameters

The error message.

The error code.

The previous throwable used for the exception chaining.

### Notes

Note:

The message is NOT binary safe.
