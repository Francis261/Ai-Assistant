# get_magic_quotes_runtime

Source: https://devdocs.io/php/function.get-magic-quotes-runtime

(PHP 4, PHP 5, PHP 7)

get_magic_quotes_runtime — Gets the current active configuration setting of magic_quotes_runtime

This function has been DEPRECATED as of PHP 7.4.0, and REMOVED as of PHP 8.0.0. Relying on this function is highly discouraged.

### Description

```
get_magic_quotes_runtime(): false
```

Always returns false.

### Parameters

This function has no parameters.

### Return Values

Always returns false.
