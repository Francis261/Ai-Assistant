# Yac::flush

Source: https://devdocs.io/php/yac.flush

(PECL yac >= 1.0.0)

Yac::flush — Flush the cache

### Description

```
public Yac::flush(): bool
```

Remove all cached values

### Parameters

This function has no parameters.

### Return Values

bool, always true
