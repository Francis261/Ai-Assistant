# OAuthProvider::addRequiredParameter

Source: https://devdocs.io/php/oauthprovider.addrequiredparameter

(PECL OAuth >= 1.0.0)

OAuthProvider::addRequiredParameter — Add required parameters

### Description

```
final public OAuthProvider::addRequiredParameter(string $req_params): bool
```

Add required oauth provider parameters.

This function is currently not documented; only its argument list is available.

### Parameters

The required parameters.

### Return Values

Returns true on success or false on failure.
