# oauth_urlencode

Source: https://devdocs.io/php/function.oauth-urlencode

(PECL OAuth >=0.99.2)

oauth_urlencode — Encode a URI to RFC 3986

### Description

```
oauth_urlencode(string $uri): string
```

Encodes a URI to » RFC 3986.

### Parameters

URI to encode.

### Return Values

Returns an » RFC 3986 encoded string.
