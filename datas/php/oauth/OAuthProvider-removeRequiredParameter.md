# OAuthProvider::removeRequiredParameter

Source: https://devdocs.io/php/oauthprovider.removerequiredparameter

(PECL OAuth >= 1.0.0)

OAuthProvider::removeRequiredParameter — Remove a required parameter

### Description

```
final public OAuthProvider::removeRequiredParameter(string $req_params): bool
```

Removes a required parameter.

This function is currently not documented; only its argument list is available.

### Parameters

The required parameter to be removed.

### Return Values

Returns true on success or false on failure.

### See Also

- OAuthProvider::setParam() - Set a parameter
- OAuthProvider::addRequiredParameter() - Add required parameters
