# oauth_get_sbs

Source: https://devdocs.io/php/function.oauth-get-sbs

(PECL OAuth >=0.99.7)

oauth_get_sbs — Generate a Signature Base String

### Description

```
oauth_get_sbs(string $http_method, string $uri, array $request_parameters = ?): string
```

Generates a Signature Base String according to pecl/oauth.

### Parameters

The HTTP method.

URI to encode.

Array of request parameters.

### Return Values

Returns a Signature Base String.
