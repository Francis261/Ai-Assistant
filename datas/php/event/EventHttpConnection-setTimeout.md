EventHttpConnection::setTimeout — Sets the timeout for the connection

### Description

```
public EventHttpConnection::setTimeout( int $timeout ): void
```

Sets the timeout for the connection

### Parameters

Timeout in seconds.

### Return Values

No value is returned.
