# Fiber::isSuspended

Source: https://devdocs.io/php/fiber.issuspended

(PHP 8 >= 8.1.0)

Fiber::isSuspended — Determines if the fiber is suspended

### Description

```
public Fiber::isSuspended(): bool
```

### Parameters

This function has no parameters.

### Return Values

Returns true if the fiber is currently suspended; otherwise false is returned.
