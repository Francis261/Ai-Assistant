# ReflectionMethod::isDestructor

Source: https://devdocs.io/php/reflectionmethod.isdestructor

(PHP 5, PHP 7, PHP 8)

ReflectionMethod::isDestructor — Checks if method is a destructor

### Description

```
public ReflectionMethod::isDestructor(): bool
```

Checks if the method is a destructor.

### Parameters

This function has no parameters.

### Return Values

true if the method is a destructor, otherwise false

### See Also

- ReflectionMethod::isConstructor() - Checks if method is a constructor
