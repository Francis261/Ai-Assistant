# ReflectionProperty::isPrivate

Source: https://devdocs.io/php/reflectionproperty.isprivate

(PHP 5, PHP 7, PHP 8)

ReflectionProperty::isPrivate — Checks if property is private

### Description

```
public ReflectionProperty::isPrivate(): bool
```

Checks whether the property is private.

### Parameters

This function has no parameters.

### Return Values

true if the property is private, false otherwise.

Note: Note this refers only to the main visibility, and not to a set-visibility, if specified.

### See Also

- ReflectionProperty::isPublic() - Checks if property is public
- ReflectionProperty::isProtected() - Checks if property is protected
- ReflectionProperty::isReadOnly() - Checks if property is readonly
- ReflectionProperty::isStatic() - Checks if property is static
