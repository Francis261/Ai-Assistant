# ReflectionParameter::export

Source: https://devdocs.io/php/reflectionparameter.export

(PHP 5, PHP 7)

ReflectionParameter::export — Exports

This function has been DEPRECATED as of PHP 7.4.0, and REMOVED as of PHP 8.0.0. Relying on this function is highly discouraged.

### Description

```
public static ReflectionParameter::export(string $function, string $parameter, bool $return = ?): string
```

Exports.

This function is currently not documented; only its argument list is available.

### Parameters

The function name.

The parameter name.

Setting to true will return the export, as opposed to emitting it. Setting to false (the default) will do the opposite.

### Return Values

The exported reflection.
