# ReflectionClass::getTraits

Source: https://devdocs.io/php/reflectionclass.gettraits

(PHP 5 >= 5.4.0, PHP 7, PHP 8)

ReflectionClass::getTraits — Returns an array of traits used by this class

### Description

```
public ReflectionClass::getTraits(): array
```

Get the array of traits used by this class.

### Parameters

This function has no parameters.

### Return Values

Returns an array with trait names in keys and instances of trait's ReflectionClass in values. Returns null in case of an error.
