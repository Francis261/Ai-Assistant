# ReflectionConstant::getFileName

Source: https://devdocs.io/php/reflectionconstant.getfilename

(PHP 8 >= 8.5.0)

ReflectionConstant::getFileName — Gets name of the defining file

### Description

```
public ReflectionConstant::getFileName(): string|false
```

Gets the filename of the file in which the constant has been defined.

### Parameters

This function has no parameters.

### Return Values

Returns the filename of the file in which the constant has been defined. If the constant is defined in the PHP core or in a PHP extension, false is returned.
