# ReflectionFunctionAbstract::getExtension

Source: https://devdocs.io/php/reflectionfunctionabstract.getextension

(PHP 5 >= 5.2.0, PHP 7, PHP 8)

ReflectionFunctionAbstract::getExtension — Gets extension info

### Description

```
public ReflectionFunctionAbstract::getExtension(): ?ReflectionExtension
```

Get the extension information of a function.

### Parameters

This function has no parameters.

### Return Values

The extension information, as a ReflectionExtension object, or null for user-defined functions.

- ReflectionFunctionAbstract::getExtensionName() - Gets extension name
