# SolrQuery::getFacetFields

Source: https://devdocs.io/php/solrquery.getfacetfields

(PECL solr >= 0.9.2)

SolrQuery::getFacetFields — Returns all the facet fields

### Description

```
public SolrQuery::getFacetFields(): array
```

Returns all the facet fields

### Parameters

This function has no parameters.

### Return Values

Returns an array of all the fields and null if none was set
