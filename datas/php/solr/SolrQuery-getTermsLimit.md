# SolrQuery::getTermsLimit

Source: https://devdocs.io/php/solrquery.gettermslimit

(PECL solr >= 0.9.2)

SolrQuery::getTermsLimit — Returns the maximum number of terms Solr should return

### Description

```
public SolrQuery::getTermsLimit(): int
```

Returns the maximum number of terms Solr should return

### Parameters

This function has no parameters.

### Return Values

Returns an integer on success and null if not set.
