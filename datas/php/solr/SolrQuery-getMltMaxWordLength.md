# SolrQuery::getMltMaxWordLength

Source: https://devdocs.io/php/solrquery.getmltmaxwordlength

(PECL solr >= 0.9.2)

SolrQuery::getMltMaxWordLength — Returns the maximum word length above which words will be ignored

### Description

```
public SolrQuery::getMltMaxWordLength(): int
```

Returns the maximum word length above which words will be ignored

### Parameters

This function has no parameters.

### Return Values

Returns an integer on success and null if not set.
