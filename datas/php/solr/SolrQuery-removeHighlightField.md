# SolrQuery::removeHighlightField

Source: https://devdocs.io/php/solrquery.removehighlightfield

(PECL solr >= 0.9.2)

SolrQuery::removeHighlightField — Removes one of the fields used for highlighting

### Description

```
public SolrQuery::removeHighlightField(string $field): SolrQuery
```

Removes one of the fields used for highlighting.

### Parameters

The name of the field

### Return Values

Returns the current SolrQuery object, if the return value is used.
