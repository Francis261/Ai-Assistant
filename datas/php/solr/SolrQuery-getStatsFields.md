# SolrQuery::getStatsFields

Source: https://devdocs.io/php/solrquery.getstatsfields

(PECL solr >= 0.9.2)

SolrQuery::getStatsFields — Returns all the statistics fields

### Description

```
public SolrQuery::getStatsFields(): array
```

Returns all the statistics fields

### Parameters

This function has no parameters.

### Return Values

Returns an array on success and null if not set.
