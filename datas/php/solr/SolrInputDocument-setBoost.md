# SolrInputDocument::setBoost

Source: https://devdocs.io/php/solrinputdocument.setboost

(PECL solr >= 0.9.2)

SolrInputDocument::setBoost — Sets the boost value for this document

### Description

```
public SolrInputDocument::setBoost(float $documentBoostValue): bool
```

Sets the boost value for this document.

### Parameters

The index-time boost value for this document.

### Return Values

Returns true on success or false on failure.
