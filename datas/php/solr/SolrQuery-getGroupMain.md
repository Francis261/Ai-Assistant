# SolrQuery::getGroupMain

SolrQuery::getGroupMain — Returns the group.main value

### Description

```
public SolrQuery::getGroupMain(): bool
```

Returns the group.main value

### Parameters

This function has no parameters.

### Return Values

### See Also
