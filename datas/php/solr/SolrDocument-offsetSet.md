# SolrDocument::offsetSet

Source: https://devdocs.io/php/solrdocument.offsetset

(PECL solr >= 0.9.2)

SolrDocument::offsetSet — Adds a field to the document

### Description

```
public SolrDocument::offsetSet(string $fieldName, string $fieldValue): void
```

Used when the object is treated as an array to add a field to the document.

### Parameters

The name of the field.

The value for this field.

### Return Values

Returns true on success or false on failure.
