# SolrQuery::getExpand

Source: https://devdocs.io/php/solrquery.getexpand

(PECL solr >= 2.2.0)

SolrQuery::getExpand — Returns true if group expanding is enabled

### Description

```
public SolrQuery::getExpand(): bool
```

Returns true if group expanding is enabled

### Parameters

This function has no parameters.

### Return Values

Returns whether group expanding is enabled.
