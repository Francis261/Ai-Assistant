# SolrQuery::getGroupLimit

Source: https://devdocs.io/php/solrquery.getgrouplimit

(PECL solr >= 2.2.0)

SolrQuery::getGroupLimit — Returns the group.limit value

### Description

```
public SolrQuery::getGroupLimit(): int
```

Returns the group.limit value

### Parameters

This function has no parameters.

### Return Values

### See Also

- SolrQuery::setGroupLimit() - Specifies the number of results to return for each group. The server default value is 1
