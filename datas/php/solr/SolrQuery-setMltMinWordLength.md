# SolrQuery::setMltMinWordLength

Source: https://devdocs.io/php/solrquery.setmltminwordlength

(PECL solr >= 0.9.2)

SolrQuery::setMltMinWordLength — Sets the minimum word length

### Description

```
public SolrQuery::setMltMinWordLength(int $minWordLength): SolrQuery
```

Sets the minimum word length below which words will be ignored.

### Parameters

The minimum word length below which words will be ignored

### Return Values

Returns the current SolrQuery object, if the return value is used.
