# SolrQuery::getMltCount

Source: https://devdocs.io/php/solrquery.getmltcount

(PECL solr >= 0.9.2)

SolrQuery::getMltCount — Returns the number of similar documents to return for each result

### Description

```
public SolrQuery::getMltCount(): int
```

Returns the number of similar documents to return for each result

### Parameters

This function has no parameters.

### Return Values

Returns an integer on success and null if not set.
