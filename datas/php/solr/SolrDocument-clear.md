# SolrDocument::clear

Source: https://devdocs.io/php/solrdocument.clear

(PECL solr >= 0.9.2)

SolrDocument::clear — Drops all the fields in the document

### Description

```
public SolrDocument::clear(): bool
```

Resets the current object. Discards all the fields and resets the document boost to zero.

### Parameters

This function has no parameters.

### Return Values

Returns true on success or false on failure.
