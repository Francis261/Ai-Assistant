# SolrDocument::__set

Source: https://devdocs.io/php/solrdocument.set

(PECL solr >= 0.9.2)

SolrDocument::__set — Adds another field to the document

### Description

```
public SolrDocument::__set(string $fieldName, string $fieldValue): bool
```

Adds another field to the document. Used to set the fields as new properties.

### Parameters

Name of the field.

Field value.

### Return Values

Returns true on success or false on failure.
