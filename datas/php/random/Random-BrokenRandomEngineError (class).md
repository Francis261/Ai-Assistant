# The Random\BrokenRandomEngineError class

Source: https://devdocs.io/php/class.random-brokenrandomengineerror

## Introduction

(PHP 8 >= 8.2.0)

Indicates that the used Random\Engine is broken, e.g. because it is severely biased.
