# sodium_crypto_kx_publickey

Source: https://devdocs.io/php/function.sodium-crypto-kx-publickey

(PHP 7 >= 7.2.0, PHP 8)

sodium_crypto_kx_publickey — Extract the public key from a crypto_kx keypair

### Description

```
sodium_crypto_kx_publickey(#[\SensitiveParameter] string $key_pair): string
```

Extract the public key from a crypto_kx keypair.

### Parameters

X25519 keypair, such as one generated by sodium_crypto_kx_keypair().

### Return Values

X25519 public key.
