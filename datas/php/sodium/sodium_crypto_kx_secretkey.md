# sodium_crypto_kx_secretkey

Source: https://devdocs.io/php/function.sodium-crypto-kx-secretkey

(PHP 7 >= 7.2.0, PHP 8)

sodium_crypto_kx_secretkey — Extract the secret key from a crypto_kx keypair.

### Description

```
sodium_crypto_kx_secretkey(#[\SensitiveParameter] string $key_pair): string
```

Extract the secret key from a crypto_kx keypair.

### Parameters

X25519 keypair, such as one generated by sodium_crypto_kx_keypair().

### Return Values

X25519 secret key.
