# The PharException class

Source: https://devdocs.io/php/class.pharexception

## Introduction

(PHP 5 >= 5.3.0, PHP 7, PHP 8, PECL phar >= 1.0.0)

The PharException class provides a phar-specific exception class for try/catch blocks.
