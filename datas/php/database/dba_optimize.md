# dba_optimize

Source: https://devdocs.io/php/function.dba-optimize

(PHP 4, PHP 5, PHP 7, PHP 8)

dba_optimize — Optimize database

### Description

```
dba_optimize(Dba\Connection $dba): bool
```

dba_optimize() optimizes the underlying database.

### Parameters

A Dba\Connection instance, returned by dba_open() or dba_popen().

### Return Values

Returns true on success or false on failure.
