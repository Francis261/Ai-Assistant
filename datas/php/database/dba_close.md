# dba_close

Source: https://devdocs.io/php/function.dba-close

(PHP 4, PHP 5, PHP 7, PHP 8)

dba_close — Close a DBA database

### Description

```
dba_close(Dba\Connection $dba): void
```

dba_close() closes the established database and frees all resources of the specified database handle.

### Parameters

A Dba\Connection instance, returned by dba_open() or dba_popen().

### Return Values

No value is returned.
