# apcu_clear_cache

Source: https://devdocs.io/php/function.apcu-clear-cache

(PECL apcu >= 4.0.0)

apcu_clear_cache — Clears the APCu cache

### Description

```
apcu_clear_cache(): bool
```

Clears the cache.

### Parameters

This function has no parameters.

### Return Values

Returns true always
