Yaf_Request_Abstract::clearParams — Remove all params

### Description

```
public Yaf_Request_Abstract::clearParams(): bool
```

Remove all params set by router, or Yaf_Request_Abstract::setParam()

### Parameters

This function has no parameters.

### Return Values

bool
