# Yaf_Dispatcher::getApplication

Source: https://devdocs.io/php/yaf-dispatcher.getapplication

(Yaf >=1.0.0)

Yaf_Dispatcher::getApplication — Retrieve the application

### Description

```
public Yaf_Dispatcher::getApplication(): Yaf_Application
```

Retrieve the Yaf_Application instance. same as Yaf_Application::app().

### Parameters

This function has no parameters.

### Return Values
