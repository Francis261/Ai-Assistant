# Dom\ChildNode::remove

Source: https://devdocs.io/php/dom-childnode.remove

(PHP 8 >= 8.4.0)

Dom\ChildNode::remove — Removes the node

### Description

```
public Dom\ChildNode::remove(): void
```

Removes the node.

### Parameters

This function has no parameters.

### Return Values

No value is returned.
