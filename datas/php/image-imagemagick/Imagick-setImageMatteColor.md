# Imagick::setImageMatteColor

Source: https://devdocs.io/php/imagick.setimagemattecolor

(PECL imagick 2, PECL imagick 3)

Imagick::setImageMatteColor — Sets the image matte color

This function has been DEPRECATED as of Imagick 3.4.4. Relying on this function is highly discouraged.

### Description

```
public Imagick::setImageMatteColor(mixed $matte): bool
```

Sets the image matte color.

### Parameters

### Return Values

Returns true on success.

### Errors/Exceptions

Throws ImagickException on error.
