# Imagick::flattenImages

Source: https://devdocs.io/php/imagick.flattenimages

(PECL imagick 2, PECL imagick 3)

Imagick::flattenImages — Merges a sequence of images

This function has been DEPRECATED as of Imagick 3.4.4. Relying on this function is highly discouraged.

### Description

```
public Imagick::flattenImages(): Imagick
```

Merges a sequence of images. This is useful for combining Photoshop layers into a single image.

### Parameters

This function has no parameters.

### Return Values

Returns true on success.

### Errors/Exceptions

Throws ImagickException on error.
