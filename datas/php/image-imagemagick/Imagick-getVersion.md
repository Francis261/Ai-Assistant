# Imagick::getVersion

Source: https://devdocs.io/php/imagick.getversion

(PECL imagick 2, PECL imagick 3)

Imagick::getVersion — Returns the ImageMagick API version

### Description

```
public static Imagick::getVersion(): array
```

Returns the ImageMagick API version as a string and as a number.

### Parameters

This function has no parameters.

### Return Values

Returns the ImageMagick API version as a string and as a number.

### Errors/Exceptions

Throws ImagickException on error.
