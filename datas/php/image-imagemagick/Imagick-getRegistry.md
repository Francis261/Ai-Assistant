# Imagick::getRegistry

Source: https://devdocs.io/php/imagick.getregistry

(PECL imagick 3 >= 3.3.0)

Imagick::getRegistry — Get a StringRegistry entry

### Description

```
public static Imagick::getRegistry(string $key): string
```

Get the StringRegistry entry for the named key or false if not set.

### Parameters

The entry to get.
