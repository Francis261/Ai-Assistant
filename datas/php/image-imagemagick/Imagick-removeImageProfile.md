# Imagick::removeImageProfile

Source: https://devdocs.io/php/imagick.removeimageprofile

(PECL imagick 2, PECL imagick 3)

Imagick::removeImageProfile — Removes the named image profile and returns it

### Description

```
public Imagick::removeImageProfile(string $name): string
```

Removes the named image profile and returns it.

### Parameters

### Return Values

Returns a string containing the profile of the image.

### Errors/Exceptions

Throws ImagickException on error.
