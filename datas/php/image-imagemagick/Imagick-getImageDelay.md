Imagick::getImageDelay — Gets the image delay

### Description

```
public Imagick::getImageDelay(): int
```

Gets the image delay.

### Parameters

This function has no parameters.

### Return Values

Returns the image delay.

### Errors/Exceptions

Throws ImagickException on error.
