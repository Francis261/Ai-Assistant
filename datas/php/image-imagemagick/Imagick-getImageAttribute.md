# Imagick::getImageAttribute

Source: https://devdocs.io/php/imagick.getimageattribute

(PECL imagick 2, PECL imagick 3)

Imagick::getImageAttribute — Returns a named attribute

This function has been DEPRECATED as of Imagick 3.4.4. Relying on this function is highly discouraged.

### Description

```
public Imagick::getImageAttribute(string $key): string
```

Returns a named attribute.

### Parameters

The key of the attribute to get.
