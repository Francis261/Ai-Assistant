# Imagick::getImageColorspace

Source: https://devdocs.io/php/imagick.getimagecolorspace

(PECL imagick 2, PECL imagick 3)

Imagick::getImageColorspace — Gets the image colorspace

### Description

```
public Imagick::getImageColorspace(): int
```

Gets the image colorspace.

### Parameters

This function has no parameters.

### Return Values

Returns an integer which can be compared against COLORSPACE constants.
