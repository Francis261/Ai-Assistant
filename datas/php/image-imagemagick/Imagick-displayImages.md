# Imagick::displayImages

Source: https://devdocs.io/php/imagick.displayimages

(PECL imagick 2, PECL imagick 3)

Imagick::displayImages — Displays an image or image sequence

### Description

```
public Imagick::displayImages(string $servername): bool
```

Displays an image or image sequence on a X server.

### Parameters

The X server name

### Return Values

Returns true on success.

### Errors/Exceptions

Throws ImagickException on error.
