# Imagick::setImageInterpolateMethod

Source: https://devdocs.io/php/imagick.setimageinterpolatemethod

(PECL imagick 2, PECL imagick 3)

Imagick::setImageInterpolateMethod — Sets the image interpolate pixel method

### Description

```
public Imagick::setImageInterpolateMethod(int $method): bool
```

Sets the image interpolate pixel method.

### Parameters

The method is one of the Imagick::INTERPOLATE_* constants

### Return Values

Returns true on success.
