# Imagick::deconstructImages

Source: https://devdocs.io/php/imagick.deconstructimages

(PECL imagick 2, PECL imagick 3)

Imagick::deconstructImages — Returns certain pixel differences between images

### Description

```
public Imagick::deconstructImages(): Imagick
```

Compares each image with the next in a sequence and returns the maximum bounding region of any pixel differences it discovers.

### Parameters

This function has no parameters.

### Return Values

Returns a new Imagick object on success.

### Errors/Exceptions

Throws ImagickException on error.
