# Imagick::setImageIndex

Source: https://devdocs.io/php/imagick.setimageindex

(PECL imagick 2, PECL imagick 3)

Imagick::setImageIndex — Set the iterator position

This function has been DEPRECATED as of Imagick 3.4.4. Relying on this function is highly discouraged.

### Description

```
public Imagick::setImageIndex(int $index): bool
```

Set the iterator to the position in the image list specified with the index parameter.

This method has been deprecated. See Imagick::setIteratorIndex().

### Parameters

The position to set the iterator to

### Return Values

Returns true on success.

### Errors/Exceptions

Throws ImagickException on error.
