# Imagick::getInterlaceScheme

Source: https://devdocs.io/php/imagick.getinterlacescheme

(PECL imagick 2, PECL imagick 3)

Imagick::getInterlaceScheme — Gets the object interlace scheme

### Description

```
public Imagick::getInterlaceScheme(): int
```

Gets the object interlace scheme.

### Parameters

This function has no parameters.

### Return Values

Gets the wand interlace scheme.

### Errors/Exceptions

Throws ImagickException on error.
