# openssl_free_key

Source: https://devdocs.io/php/function.openssl-free-key

(PHP 4 >= 4.0.4, PHP 5, PHP 7, PHP 8)

openssl_free_key — Free key resource

This function has been DEPRECATED as of PHP 8.0.0. Relying on this function is highly discouraged.

### Description

```
#[\Deprecated] 
 openssl_free_key(OpenSSLAsymmetricKey $key): void
```

openssl_free_key() frees the key associated with the specified key from memory.

### Parameters

### Return Values

No value is returned.
